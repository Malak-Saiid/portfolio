# Optional profile assets

This directory is reserved for a future profile image supplied by Malak. The current hero uses a developer-style visual and does not require a portrait.

Files placed here are not displayed automatically. To add an image, place an optimized file such as `malak-saiid.webp` in this directory, then deliberately update the relevant section component to reference `/profile/malak-saiid.webp`. Add appropriate alternative text and explicit dimensions, and check the layout in both themes and on mobile.

Use a real, authorized image of Malak if a portrait is added. Do not substitute a stock portrait or imply an unrelated person is Malak.
